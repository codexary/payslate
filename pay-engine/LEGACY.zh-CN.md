# 继承的 Payslate 7 计算引擎

`LegacyPayEngine` 的计算过程写于 2004 年。2021 年桌面产品团队以最小改动把它迁到现代 Java 构建上，数据类型改用 record，日期改用 `java.time`。其余计算代码保留 2004 年的写法：很长的计算过程、可变计数器、手写循环、匿名比较器、可变集合、用 `double` 计数工时，以及顺序扫描税表。半分钱的测试暴露了 `double` 金额累加的舍入错误，金额因此改为按加权分钟精确计算。外围的 API、命令行程序和测试是新写的代码。重构之前，这个源文件不参加 Spotless 格式检查。这里记下这些写法，是为了不让人把它当作代码风格的范例。

`YtdAccumulator` 是桌面版的年初至今累计额，从 Payslate 7 移植过来。发现负调整会抹掉此前的累计额之后，它被修复，并重构成只对字段做一次明确的更新；现在它和新代码一样参加格式检查。
